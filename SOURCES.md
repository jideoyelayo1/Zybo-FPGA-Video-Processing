# What in this repository is hand-written

The repository holds two complete Vivado 2019.1 projects, `prewitt/` and `sobel/`,
built on Digilent's Zybo Z7-20 Pcam 5C demo. Almost everything in them is vendor
IP or tool output. This file says which files are the project's own work, and how
that was established. Nothing has been moved or deleted.

## Hand-written

| File | Lines | What it is |
|---|---:|---|
| `prewitt/prewitt.srcs/sources_1/new/vid_proc.v` | 178 | `video_processing`: greyscale, line buffers, Prewitt X/Y/magnitude, mode buttons |
| `prewitt/prewitt.srcs/sources_1/new/sqrt.v` | 29 | `sqrt_fn`, used for the magnitude mode |
| `sobel/sobel.srcs/sources_1/new/vid_proc.v` | 173 | same module with Sobel weights; no `btn[3]` handling |
| `sobel/sobel.srcs/sources_1/new/sqrt.v` | 30 | same as the Prewitt copy plus one comment line |
| `verify/` | | testbench, model and scripts added with RESULTS.md |
| `README.md`, `SOURCES.md`, `RESULTS.md` | | documentation |

The filter is 410 lines of Verilog across the four files; the two `vid_proc.v`
copies differ only in kernel weights, names and the Prewitt-only `btn[3]` line
(`diff prewitt/prewitt.srcs/sources_1/new/vid_proc.v sobel/sobel.srcs/sources_1/new/vid_proc.v`).

Owner edits inside vendor files:

- `*/constrs_1/imports/constraints/ZyboZ7_A.xdc`: 12 lines uncommented (`sw[0..3]`,
  `btn[0..3]`, `led[0..3]` pin assignments). Otherwise identical to Digilent's file.
- The block design (`*/sources_1/bd/system/system.bd`, edited in the Vivado GUI):
  `video_processing_0` inserted between `v_axi4s_vid_out_0` and `rgb2dvi_0`, and
  `btn`, `sw` and `led` ports added. The wiring can be read in
  `*/sources_1/bd/system/hw_handoff/system_bd.tcl` (search for `video_processing_0`).

## Vendor, unmodified

Checked byte for byte (`cmp`) against Digilent's
[Zybo-Z7-20-pcam-5c](https://github.com/Digilent/Zybo-Z7-20-pcam-5c) at tag
`v2019.1-1`:

- the whole SDK application, `*/*.sdk/pcam_vdma_hdmi/src/` (16 files per project:
  `main.cc`, `hdmi/VideoOutput.h`, `ov5640/*`, `platform/*`, linker script). The two
  projects' copies are identical to each other as well.
- `*/sources_1/imports/hdl/DVIClocking.vhd`, `SyncAsync.vhd`, `SyncAsyncReset.vhd`.
- `*/constrs_1/imports/constraints/auto.xdc`; `timing.xdc` differs by one trailing
  blank line.

Not compared file by file, but vendor by origin: the Digilent IP (MIPI CSI-2 RX,
MIPI D-PHY RX, AXI Bayer-to-RGB, AXI gamma correction, rgb2dvi, dynamic clock) under
`*/sources_1/bd/system/ipshared/` and `ip/`, and the Xilinx IP (VDMA, VTC,
AXI4-Stream to video out, Zynq PS, clocking wizard, interconnect, resets).

Sizes come from:

```sh
git ls-files | grep -E '<pattern>' | python3 -c "import sys,os; f=[l.strip() for l in sys.stdin]; print(len(f), round(sum(map(os.path.getsize,f))/1e6,2))"
```

The `.runs/` directories are kept on purpose: they hold the April 2023 utilisation
and timing reports that RESULTS.md quotes. Trimming the repository to sources plus a
block-design Tcl script is possible, but whether the trimmed project rebuilds can
only be checked in Vivado, so it is not done here.

## Provenance notes

- `*/sources_1/imports/vivado_proj/archive_project_summary.txt` names the starting
  point: Digilent's `Zybo-Z7-20-pcam-5c` project.
- The `.xpr` files point at an IP repository outside this repository
  (`$PPRDIR/../../FPGA/Zybo-Z7-20-pcam-5c-2019.1/...`); see the README for what to do
  when Vivado reports it missing.
